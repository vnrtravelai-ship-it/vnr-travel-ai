# RAILWAY_KNOWLEDGE_MODEL.md

# VNR Travel AI

## Railway Knowledge Model

Version: 1.0

Status: Planning

---

# Purpose

This document defines the railway-specific knowledge base of VNR Travel AI.

Unlike generic travel platforms, VNR Travel AI maintains structured railway knowledge as a permanent business asset.

This knowledge is owned by the application, not by any AI provider.

---

# Railway Knowledge Domains

The Railway Knowledge Base consists of:

- Railway Lines
- Railway Stations
- Train Services
- Scenic Railway Segments
- Heritage Stations
- Train Classes
- Seat Types
- Onboard Services
- Railway Photography Spots
- Railway Travel Seasons
- Railway Safety
- Railway Travel Tips
- Railway Souvenirs

---

# Railway Lines

Each railway line contains:

- Line ID
- Name
- Start Station
- End Station
- Distance
- Average Duration
- Scenic Rating
- Heritage Rating

Examples

- North–South Railway
- Hanoi–Hai Phong
- Hanoi–Lao Cai
- Da Nang–Hue Heritage Line

---

# Scenic Railway Segments

Each segment includes:

- Segment Name
- Start KM
- End KM
- Best Viewing Side
- Sunrise Quality
- Sunset Quality
- Landscape Type
- Photography Rating

Examples

- Hai Van Pass
- Lang Co Bay
- Ca Pass
- Nha Trang Coast

All railway knowledge belongs to VNR Travel AI.

AI Providers never own or generate railway knowledge.

AI only explains it.
